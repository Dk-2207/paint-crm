# Paint CRM + Billing
A practice full-stack project: customer management, product catalog, 
and invoicing for a small paint-selling business.

## Stack
- Backend: NestJS + Prisma + PostgreSQL
- Frontend: Next.js + Tailwind
- Deployment: Render (backend) + Vercel (frontend) + Supabase/Neon (DB)
